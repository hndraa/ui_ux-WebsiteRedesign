# BRIDA Mataram Website Redesign

**UI/UX DESIGN** | **WEBSITE REDESIGN** | **FIGMA ‧ UCD**

A UI/UX redesign project for the official website of the Regional Research and Innovation Agency (BRIDA) of Mataram City. The project focuses on improving information accessibility, navigation, visual consistency, and user experience through user research, responsive design exploration, interactive prototyping, and usability evaluation.

## 01. Project Overview

### Project Description

The BRIDA Mataram Website Redesign is a UI/UX design project completed during a two-month Field Work Practice (PKL) at Badan Riset dan Inovasi Daerah (BRIDA) Kota Mataram, from January 20 to March 21, 2025.

The project aimed to redesign the official website interface to make public information easier to find, improve navigation, and provide a more organized experience across desktop and mobile layouts.

### Problem Statement

Based on initial observations and user research documented in the project report, several issues were identified in the existing website experience:

- Navigation was difficult to understand and important information was not always easy to find.
- Some pages lacked sufficient information or presented content in an unstructured way.
- Visual elements, layout, and color combinations needed improvement.
- The website experience was not sufficiently responsive across different device sizes.
- Accessing service instructions, public information, activity details, and complaint procedures could be confusing.

### Objectives

- Redesign the website interface based on user needs.
- Improve information hierarchy and navigation clarity.
- Organize public information, services, activities, and institutional profile content.
- Explore desktop and mobile layouts.
- Evaluate the proposed design through usability testing and the System Usability Scale (SUS).

### Design Approach

The project applied **User-Centered Design (UCD)**, an iterative design approach focused on users' needs, goals, and experiences.

The process consisted of four stages:

1. **Understand the Context of Use** — Identify user characteristics, goals, frustrations, and website usability issues through research and observation.
2. **Specify User Requirements** — Translate identified pain points into user needs and design requirements.
3. **Produce Design Solutions** — Develop a sitemap, design system, low-fidelity wireframes, and high-fidelity website prototypes.
4. **Evaluate Against User Requirements** — Conduct usability testing and evaluate the prototype using the System Usability Scale (SUS).

### Design Scope

The redesign covered six main website pages:

- **Home** — Present key information and provide clearer navigation to important sections.
- **Profile** — Organize institutional information, vision and mission, responsibilities, and organizational structure.
- **Services** — Explain research and service procedures through clearer information and instructions.
- **Information** — Organize public information and documents with search, filtering, and download-oriented layouts.
- **Activities** — Present news, programs, activities, and event information in a more structured format.
- **Complaints** — Provide clearer guidance on complaint submission procedures.

### Key Deliverables

- User persona and pain point analysis.
- User needs and design requirements.
- Website sitemap.
- Design system.
- Low-fidelity wireframes for mobile and desktop.
- High-fidelity website designs for mobile and desktop.
- Interactive prototype in Figma.
- Usability testing and SUS evaluation documentation.

### Evaluation Results

The prototype was evaluated online with **25 respondents**. The evaluation included usability testing using Maze and a 10-question System Usability Scale (SUS) questionnaire.

| Evaluation | Result |
|---|---|
| Respondents | 25 |
| Usability Testing Tool | Maze |
| Evaluation Questionnaire | System Usability Scale (SUS) |
| Average SUS Score | 91.4 / 100 |
| Reported SUS Category | Excellent |

The average SUS score of **91.4** was classified as *Excellent* in the project report, indicating a positive usability evaluation of the proposed design among the participating respondents.

*Scope note: This project focused on UI/UX design and prototyping. It did not include implementation of the website's backend or database.*

### Insights

The research identified several opportunities to improve the website experience:

- Clearer navigation can help users locate important information more easily.
- Better information hierarchy can reduce confusion when browsing institutional information and documents.
- Dedicated service and complaint guidance can make procedures easier to understand.
- Consistent visual elements can create a more coherent interface.
- Desktop and mobile design exploration helps address differences in screen size and browsing context.

### Usefulness

The redesign provides a structured interface concept for presenting government information and services. It helps organize content around user goals and offers a design reference for improving the accessibility and usability of the official website.

### Practical Application

The proposed designs can serve as a reference for future website development or redesign initiatives at BRIDA Kota Mataram. Further implementation and testing would be needed to validate the design in a live website environment.
